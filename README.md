# ⏱️ Conômetro

Projeto desenvolvido para colocar em prática meus conhecimentos em **HTML5, CSS3 e JavaScript**, criando uma aplicação de cronômetro com uma interface simples, moderna e funcional.

O **Conômetro** faz parte da minha jornada de aprendizado em desenvolvimento web e foi desenvolvido com o objetivo de praticar não apenas a construção visual de uma página, mas também a criação de funcionalidades utilizando JavaScript.

## 🚀 Sobre o projeto

A proposta do projeto foi desenvolver um **cronômetro digital**, permitindo controlar a passagem do tempo diretamente pela interface.

Durante o desenvolvimento, trabalhei a integração entre **HTML, CSS e JavaScript**, utilizando JavaScript para controlar o funcionamento do cronômetro e atualizar os valores apresentados na tela.

Esse projeto representa mais uma etapa da minha evolução, colocando em prática conceitos de lógica de programação e manipulação da interface através do JavaScript.

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura da aplicação
* **CSS3** — estilização e construção da interface
* **JavaScript** — lógica e funcionamento do cronômetro

## 🎯 Objetivo

O principal objetivo deste projeto foi **colocar em prática meus conhecimentos sobre `setTimeout()` e `setInterval()` em JavaScript**, utilizando essas funções para controlar a execução de ações ao longo do tempo.

O **Conômetro** foi desenvolvido como um exercício prático para entender melhor como trabalhar com **temporizadores em JavaScript**, controlar intervalos de execução e atualizar elementos da interface de forma dinâmica.

Através desse projeto, pude aplicar esses conceitos em uma situação real, fortalecendo minha compreensão sobre **execução assíncrona, temporização e manipulação do DOM**.
